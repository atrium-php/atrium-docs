# Atrium — Docs

VitePress site for [Atrium](https://github.com/atrium-php/atrium), a free, modular, upgradable Laravel platform for multi-portal apps.

Live at: https://atrium-php.github.io/atrium-docs/

> **Read-only split.** The source is `docs/site` in the [atrium-php/atrium](https://github.com/atrium-php/atrium) monorepo, so docs change in the same pull request as the code they describe. Changes on its `main` are published here, and this repository's Deploy workflow builds GitHub Pages. Don't commit here — it is overwritten on the next publish.

## Local development

```bash
npm install
npm run docs:dev
```

## Build

```bash
npm run docs:build
```
